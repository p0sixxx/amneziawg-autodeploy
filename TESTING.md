# Проверка awgctl

## Локально

```bash
bash -n awgctl && shellcheck awgctl
bats tests/                     # функции awgctl на поддельном конфиге и awg
```

## На сервере

| Что | Команда | Ожидается |
|---|---|---|
| План без изменений | `bash /root/awgctl install --dry-run` | все `[OK]`, план |
| Ход установки | `awgctl status` | «Установка завершена» или текущий шаг |
| Итоговая проверка | `awgctl check` | 0 ошибок |
| Проверка движка | `awgctl engine check` | без FAIL |
| После перезагрузки | `reboot`, затем `awgctl check` | то же |
| Пользователь | `awgctl add test --days 1`, `awgctl list` | QR и ссылка, строка в списке со сроком |
| Рукопожатие | подключить клиента, `awgctl list` | «ВХОД» — сейчас, трафик растёт |
| Выход в интернет | на клиенте 2ip.ru | IP сервера |
| off/on | `awgctl off test` → на клиенте сайты не открываются; `awgctl on test` → открываются | |
| Удаление | `awgctl del test` | нет в `list`, конфиг не подключается |
| SSH не сломан | вход в новом окне, не закрывая старое | входит |
| Блокировка IP в РФ | `awgctl check`, раздел check-host.net | «IP доступен из России» |

UDP-порт снаружи проверить нельзя: AmneziaWG молчит на чужие пакеты. Его доступность подтверждает рукопожатие клиента.
