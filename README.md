# awgctl — AmneziaWG одной командой

Установка своего VPN-сервера AmneziaWG 3.1 (или 2.0) и управление пользователями из консоли или Telegram.

Движок — [bivlked/amneziawg-installer](https://github.com/bivlked/amneziawg-installer) (MIT): модуль ядра через DKMS из официального PPA Amnezia, параметры 3.1, клиенты, бэкапы. Код движка не меняется: awgctl скачивает закреплённую версию (сейчас **v6.2.1**) и сверяет SHA256. Что проверено в движке — [AUDIT.md](AUDIT.md).

## Установка

Нужен чистый VPS: Ubuntu 24.04, 26.04 или Debian 13, виртуализация KVM (не контейнер LXC/OpenVZ), от 1 ядра и 1 ГБ RAM.

```bash
curl -fsSLo /root/awgctl https://raw.githubusercontent.com/p0sixxx/amneziawg-autodeploy/main/awgctl
bash /root/awgctl install --name="My server" --clients=phone,laptop
```

В начале скрипт задаст два вопроса — ставить ли блокировщик рекламы и Telegram-бот (можно ответить флагами, см. ниже). Дальше всё идёт само: сервер 1–2 раза перезагрузится, после каждой перезагрузки установка продолжится без твоего участия. Через 3–5 минут зайди по SSH:

```bash
awgctl status      # ход установки; в конце — итоговая проверка
awgctl list        # пользователи
awgctl show phone  # QR и ссылка vpn://
```

Если `status` пишет «прервана» — `awgctl resume`. Ход установки в реальном времени: `tail -f /var/log/awgctl.log`.

Что делает `install`:

- **сначала обновляет систему**: `apt update` + `full-upgrade` с последними пакетами и ядром (на свежем VPS образ обычно старый; если apt занят автообновлениями после первой загрузки — ждёт); `--no-upgrade` — пропустить;
- проверяет сервер и сеть: ОС, архитектура, контейнер или ВМ, RAM, диск, DNS, доступ к GitHub и PPA, публичный IP, NAT, время, конфликты (WireGuard, Docker, 3x-ui);
- **проверяет, не заблокирован ли IP в России**: SSH-порт через check-host.net с узлов в РФ и Европе; на заблокированный IP не ставит;
- выбирает **случайный UDP-порт** 20000–59999 (у движка по умолчанию у всех 39743 — по нему сервер легко найти);
- настраивает так, как советует автор движка для сервера только под VPN: IPv6 на хосте выключен, лишние службы (snapd, packagekit, modemmanager, udisks2, unattended-upgrades…) удаляются, ufw и fail2ban включены, весь трафик клиентов идёт в туннель, клиенты изолированы друг от друга;
- профиль 3.1 со своими маскирующими пакетами I1–I5 (см. [Обфускация](#обфускация));
- модуль ядра — только из официального PPA, без готовых .deb из чужих релизов.

### Параметры `install`

| Параметр | Что |
|---|---|
| `--dry-run` | только проверки и план, ничего не меняет |
| `--name="My server"` | имя сервера в приложениях Amnezia (по умолчанию «AWG Server») |
| `--clients=a,b` | пользователи сразу (иначе `my_phone`, `my_laptop`) |
| `--port=N` | свой порт вместо случайного |
| `--mobile` | 443/udp и пресет для мобильных операторов |
| `--protocol=2.0` | сервер для клиентов без 3.1: роутеры GL.iNet на штатной прошивке, Hiddify |
| `--endpoint=АДРЕС` | адрес для клиентов (домен; сервер за NAT) |
| `--keep-packages` / `--keep-ipv6` | не удалять службы / не выключать IPv6 на хосте |
| `--obfs=engine` | I1 как у движка (под DNS) вместо своих I1–I5 под QUIC |
| `--adblock` | поставить DNS-блокировщик рекламы |
| `--bot --tg-admins=ID` | поставить Telegram-бот (токен — переменной `AWGRAM_TOKEN=…` или спросит) |
| `--no-extras` | без дополнений и без вопросов |
| `--no-upgrade` | не обновлять систему перед установкой |
| `--allow-blocked-ip` / `--skip-external-check` | ставить на IP, недоступный из РФ / не проверять IP |

## Пользователи

| Команда | Что |
|---|---|
| `awgctl add Ivan [--days 30] [--psk]` | новый пользователь: сразу QR, ссылка `vpn://` и файл `.conf` |
| `awgctl list` | все: IP, вкл/выкл, сколько скачал и отдал, последний вход, срок |
| `awgctl show Ivan` | QR + ссылка + путь к конфигу |
| `awgctl qr Ivan` / `link Ivan` / `conf Ivan` | только QR / ссылка `vpn://` / текст конфига |
| `awgctl renew Ivan 30` | продлить на 30 дней от сегодня (`0` — бессрочно) |
| `awgctl off Ivan` / `on Ivan` | временно отключить / включить (ключи и конфиг те же) |
| `awgctl del Ivan` | удалить |

**Как поделиться.** Ссылку из `awgctl link Ivan` открывают в **Amnezia VPN** или **AmneziaWG** («Вставить из буфера»), QR сканируют там же; для роутера — текст из `awgctl conf Ivan`. Каждому человеку и устройству — свой пользователь: доступ отзывается у одного, не трогая остальных. В конфиге приватный ключ — не пересылай его в открытых чатах.

**Срок** (`--days`, `renew`): по истечении пользователь удаляется автоматически (cron движка). **Трафик** в `list` считается с последнего запуска интерфейса awg0.

**Клиенты, понимающие 3.1:** AmneziaWG (iOS/macOS 3.1.4+ — есть в российском App Store; Android 3.1.4+; Windows 3.1.0+), WG Tunnel 5.6+, Amnezia VPN 5.0.1.5+ (нет в российском App Store), OpenWrt с `awg-openwrt` 25.12.5+. Штатная прошивка GL.iNet и Hiddify — только 2.0: для них нужен отдельный сервер с `--protocol=2.0`.

## Сервер

| Команда | Что |
|---|---|
| `awgctl check` | сервис, порт, NAT, ufw, рукопожатия, ждущие обновления системы, доступность IP из России |
| `awgctl backup` / `restore [файл]` | бэкап ключей и пользователей / восстановление |
| `awgctl engine <команда …>` | любая команда движка: `diagnose`, `stats`, `regen`, `restart`… |
| `awgctl uninstall` | удалить AmneziaWG и awgctl |

| Порт | Что |
|---|---|
| SSH (текущий) /tcp | не меняется, разрешается в ufw до его включения |
| случайный 20000–59999 /udp (или 443) | AmneziaWG |

Файлы: конфиги и QR — `/root/awg/`, сервер — `/etc/amnezia/amneziawg/awg0.conf`, состояние awgctl — `/var/lib/awgctl/`, лог — `/var/log/awgctl.log`.

**Обновить awgctl** (пользователи и настройки не затрагиваются):

```bash
curl -fsSLo /usr/local/sbin/awgctl https://raw.githubusercontent.com/p0sixxx/amneziawg-autodeploy/main/awgctl && chmod 700 /usr/local/sbin/awgctl
```

GitHub отдаёт `main` из кэша до 5 минут; чтобы сразу получить свежую версию, вместо `main` подставь хеш коммита.

**Сменить имя сервера** в приложениях после установки:

```bash
INIT=/root/awg/awgsetup_cfg.init
sed -i '/^export AWG_SERVER_NAME=/d' "$INIT"
printf "export AWG_SERVER_NAME='%s'\n" 'Новое имя' >>"$INIT"
awgctl engine --yes regen
```

Ключи не меняются, старые профили работают; новое имя появится после переимпорта (`awgctl show <имя>`).

## Обфускация

Профиль AmneziaWG 3.1:

| Параметр | Значение | Где действует |
|---|---|---|
| Шифрование заголовков `HeaderProtectionKey` | вкл, свой случайный ключ на сервер | обе стороны |
| Паддинг `ContentPaddingAddition` | вкл, 32–128 | отправитель |
| `H1`–`H4` | 1 · 2 · 3 · 4 (диапазоны не нужны: тип пакета зашифрован) | обе стороны |
| `S1`–`S4` | случайные, не меньше 12 (из них берётся nonce) | обе стороны |
| `I1`–`I5` | пять своих пакетов под QUIC Initial, уникальных для сервера | инициатор (клиент) |
| `DisableCookies` | выкл | — |
| `RandomTrailers` | **выкл**: по замеру автора движка вместе с остальной обфускацией скорость падает в 85–133 раза | — |
| Таймеры `RekeyAfterTime`, `KeepaliveTimeout`… | не задаются: это клиентские параметры, движок не пишет их в профили | — |

`awgctl obfs` — показать параметры сервера. `awgctl obfs quic` — выпустить новые I1–I5 на уже установленном сервере: старые профили продолжают работать, новая маскировка — после переимпорта (`awgctl show <имя>`).

## Дополнения

Спрашиваются в начале `install` (после перезагрузок спросить уже не у кого) и ставятся в конце. Позже — отдельными командами.

### Блокировка рекламы по DNS

`awgctl adblock on|off|status`. [Blocky](https://github.com/0xERR0R/blocky) v0.34.0 (SHA256 закреплён) со списками Hagezi Pro + TIF; конфиг из [Cueuler/amneziawg_dns_adblock](https://github.com/Cueuler/amneziawg_dns_adblock) (закреплённый коммит). Слушает только адрес сервера внутри туннеля. DNS-запросы всех клиентов перенаправляются на него на сервере, поэтому **конфиги переимпортировать не нужно**, и блокировка действует даже у клиентов с прописанным 1.1.1.1. Не режет рекламу внутри YouTube и не работает, если в браузере включён «Безопасный DNS» (DoH).

### Telegram-бот

`awgctl bot` — ставит [awgram](https://github.com/ekuraev/awgram) v0.13.2 (установщик закреплён по SHA256). Нужны токен от [@BotFather](https://t.me/BotFather) и свой ID от [@userinfobot](https://t.me/userinfobot); несколько админов — через запятую. Без вопросов:

```bash
AWGRAM_TOKEN='123456:AA…' awgctl bot --tg-admins=111111111,222222222
```

- **Один бот — один сервер.** Telegram отдаёт сообщения только одному получателю на токен, поэтому для каждого сервера создай отдельного бота.
- Бот работает в режиме root. Режим hardened (отдельный пользователь) с этим движком не работает: движок ставит `chmod 700/600` на `/root/awg` и конфиги, и бот перестаёт их видеть; изоляции он и не давал — sudoers разрешает боту скрипт управления с любыми аргументами. Если бот поставлен вручную в hardened и падает с «manage_script не найден» — `awgctl bot fix`.
- Пользователи, созданные в боте и в `awgctl`, видны и там и там; `awgctl off/on` бот не видит.
- Сменить админов: `awgram-setup config --admins 111111111,222222222 && systemctl restart awgram`. Сменить токен и прочее: `awgram-setup config`. Журнал: `journalctl -u awgram -n 30`.
- Удалить бота (VPN и пользователи остаются): `awgram-setup uninstall --purge`.

## Удаление

```bash
awgctl uninstall
```

Удаляет AmneziaWG встроенной командой движка (перед этим он делает бэкап), блокировщик, правила и службы awgctl, затем сам awgctl. Telegram-бот удаляется отдельно: `awgram-setup uninstall --purge`.
