## Что проверено

- Все сетевые обращения (`curl`, `wget`, `git clone`) в install/common/manage: GitHub автора (скрипты, ARM-пакеты), PPA Amnezia, git модуля Amnezia, сервисы определения IP (ipify, icanhazip, ifconfig.me и др.). Телеметрии и отправки данных о сервере нет. `wget …/v$want/…` в manage — только печатаемая подсказка, не выполняется.
- `eval`/`source` внешних данных: конфиги читаются белым списком ключей («без source/eval»).
- Ключи: приватные ключи, PSK и `HeaderProtectionKey` в `/root/awg` и `/etc/amnezia/amneziawg` с правами 600; в логах маскируются (`[HIDDEN]`).
- Параметры 3.1 (`generate_awg_params`): `HeaderProtectionKey` — случайные 32 байта на сервер; H1–H4 = 1,2,3,4 при Header Protection; S1–S4 ≥ 12 (модуль ядра иначе вернёт `-EINVAL`, проверено в `netlink.c`: `HEADER_PROTECTION_NONCE_SIZE = 12`); исключены коллизии длин (S1+56≠S2, S2+28≠S3, S4 по таблице). `RandomTrailers`/`DisableCookies` по умолчанию выключены. I1 (CPS) — случайный DNS-подобный пакет на каждый сервер, не пример из документации.
- Фаервол: ufw, SSH-порт определяется (ss / sshd -T / sshd_config) и разрешается до `ufw enable`.
- Защита от CVE в apt (запрет повторов скачивания на время установки) и от CVE-2026-98432 (правило против TCP с IP-опциями).

## Находки и что делает awgctl

| # | Находка | Риск | Решение |
|---|---|---|---|
| 1 | Переменная окружения `AWG_BRANCH`, отличная от тега, **молча отключала** проверку SHA256 скачиваемых awg_common.sh/manage_amneziawg.sh (только предупреждение в лог) | подмена кода, который выполняется от root | awgctl запускает движок с вычищенным `AWG_BRANCH` (`env -u AWG_BRANCH …`), поэтому проверка всегда включена |
| 2 | На ARM по умолчанию ставится готовый .deb модуля ядра из релиза автора; SHA256 скачивается из того же места | целостность, но не подлинность: модуль ядра от третьей стороны | awgctl всегда передаёт `--no-prebuilt` — модуль только из официального PPA через DKMS |
| 3 | По умолчанию установщик удаляет snapd, unattended-upgrades, modemmanager, cloud-init и др. (с согласием) | unattended-upgrades тоже удаляется — обновления безопасности ставить вручную | по решению владельца оставлено как у автора (экономия RAM на 1 ГБ); `--keep-packages` — сохранить |
| 4 | По умолчанию отключает IPv6 на хосте глобально | расходится с требованием «не отключать IPv6 глобально» | по решению владельца оставлено как у автора (однозадачный VPN-сервер, меньше поверхность атаки); `--keep-ipv6` — не отключать. У клиентов в AllowedIPs есть `::/0`, их IPv6 мимо VPN не утекает |
| 5 | Порт по умолчанию 39743/udp одинаков у всех установок | сервер легко найти сканированием | awgctl выбирает случайный порт 20000–59999 (или 443 при `--mobile`) |
| 6 | Нет проверки, не заблокирован ли IP сервера в РФ | VPN ставится на уже бесполезный IP | awgctl проверяет SSH-порт через check-host.net из РФ и Европы и останавливается, если IP недоступен только из РФ |
| 7 | `ContentPaddingAddition` 32–128 в профиле 3.1 | sing-box-extended падает при значении > 16 (issue #158 у sing-box-extended) | не меняли: официальные клиенты работают; для sing-box задать вручную |

## Чего аудит не покрывает

Установщик — около 40 тыс. строк bash. Проверялись все места с сетью, правами, ключами, apt, фаерволом и генерацией параметров; бизнес-логика шагов (resume, restore, cascade, WARP) построчно не проверялась. Смена версии движка: повторить проверку по этому списку на `git diff v6.2.1..vNEW -- install_amneziawg.sh awg_common.sh manage_amneziawg.sh`, затем обновить `ENGINE_VER` и `ENGINE_SHA256` в awgctl.
